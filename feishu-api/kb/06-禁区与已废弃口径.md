## ⚠️ 素材级散点的陷阱
`六月素材投放消耗.xlsx` 有 14 个品广×GMVMAX 重合素材，截面 **ρ=0.82 / r=0.93 / R²=0.86**，看着像"品广有用"——
**这是反向选择假象，不能用来证明品广有用**：
1. 是 GMVMAX 已经跑得好的素材才被挑去上品广（案例 A `7646800066883194132`：GMVMAX 6/14 先起量，品广 6/17 才进场 = **品广追赢家**）
2. 品广日级加投也不带动 GMVMAX（旗舰 `7642356927774739733`：品广 +65% 而 GMVMAX 收入 −5%；3 条常投素材日级 r = 0.00 / 0.01 / 0.52）
3. 品广 vs GMVMAX ROI 相关 ≈ 0

**但反过来也不能证明品广没用** —— 品广是滞后种草账（funnel ROI 1.6），日级 GMVMAX 看不到种草效应很正常。**两边都只能靠 holdout 定。**

## ⚠️ 小时级"共振"是时段假象
品广 / GMVMAX 都晚高峰齐升 = 时段共因；剔时段 + 日级后相关性 ≈ 0。
反例：日级品广加投但 GMV 6/19 见顶后回落；最大收入日 6/6（双日大促）品广却很低。

## 数据缺口（还没补上的）
- 越南 TikTok Shop **罗盘未开放搜索分析** → 品牌词/相关词的**搜索 GMV 算不了**（只有搜索量）
- **无 BLS**（品牌提升研究不可用）→ 品广品牌效果只能用搜索替代验证
- **品广因果无法做 on/off 控制实验**

**holdout 怎么做**：自助后台 A/B-Split-Test 只能比"投A vs 投B"、做不出"零曝光对照"；真随机 holdout 只有 Conversion Lift / BLS（代理立项、有门槛）。拿不到就走 **geo holdout**（按省份配平分两组、品广只投 test 省、订单收货地归因 GMV、DiD 读 iROAS；GMVMAX/直播两组冻结）。年龄只用于投后画像看谁响应，**不当切分轴**。
