# 03 · 素材决策与阈值

## 不挂车投流选品准标
**第一关（自然裸跑 3 天）**：VV > 1000 / 6sVTR > 34% / 互动 ≥ 3%
**第二关（投流后）**：6sVTR ≥ 15% & 种草效率 ≥ 2.4% & **CPCo ≤ 0.03**；GMV Max ROI ≥ 1.5 仅兜底

⚠️ **已知矛盾**：老板实际按带货 GMV/订单选品（预算几乎跟随 GMV 排名）。11 条在投里仅 1 条（thaokhongpeooo）符合种草准标；被跳过的高钩子素材（nngaan 新 / hinnie）反而符合 → **选品逻辑错配**。

## 预算增减规则
- **加**：6sVTR ≥ 15% & 效率 ≥ 2.4% & CPCo ≤ 0.03 → +30~50%（单组封顶 ~$200）
- **砍**：6sVTR < 8% 或 CPCo > 0.05
- **种草差但能收割** → 转 GMV Max
- 优质素材**每周确认接续**（防 hinnie 式断档）

## 30 天实测阈值（品广 21 条 + GMVMAX 2482 条，重合 16 条）
- **收割达标线**：ROI ≥ 3 · 成本 ≥ $100 · 订单 ≥ 30 → 18 条达标，均值 ROI 4.96 / 转化率 1.4% / 完播 1.05%
- **种草优质线**：CPCo ≤ $0.03 · 新增 Co ≥ 20k · 6秒专注观看率 ≥ 15–19%（**品广后台口径，不是 playbook 的 34%**）· 互动率 ≥ 0.9% · 种草效率 ≥ 2.2%

### ⭐ 最关键的一条反直觉结论
> **内容指标反推不出收割。**
> 6sVTR / 互动 vs 收割 ROI 相关 ≈ 0（Spearman），赢家和差素材的内容画像几乎一样。
> **完播率是唯一弱前哨**（vs 转化率 +0.46）。

所以：**内容只能筛掉差的，选不出好的。选好的必须靠小预算品广实测 CPCo/Co，不能靠拍内容。**

## "不挂车能不能上品广" = 三道闸
1. **内容关**：完播 / 互动 / 自然 VV 过最低线，筛掉差的
2. **画像参照**：弱信号只用来排序
3. **小预算品广实测 CPCo**：≤ $0.03 且 Co 起量 → 留/放大；> $0.05 → 砍

**用户最终简化版操作**：内容团队审核素材质量 → 觉得好的直接上品广 **$30/天 × 跑 3 天** → 看数据，达标（CPCo ≤ 0.03 / Co 起量）留，不达标删。

## 素材三分类（KOL/KOC 都留一定比例不挂车）
| 类型 | 谁 | 怎么处理 |
|---|---|---|
| 种割一体 | KOL | 挂车收割，双优可上品广 |
| **纯种草** | 功效卖点 | **不挂车 · 上品广 —— 要筛的就是这批** |
| 纯收割 | 机制 | 挂车，不上品广 |

不挂车比例起步：**KOL 20–30%、KOC 40–60%**（AB 校准）。

## AB 实验设计
A = 挂车上品广 / B = 不挂车上品广（最好同素材两版）。基线配平、同期同口径。
**比种草效率不比当天 GMV**（不挂车无购物车不能直接归因）：CPCo↓ / 新增 Co / Co→成交流转。周期 ≥ 3–4 周。

## 「内容先验 · 赢家投流」（Liquid Death 打法）
① 扒同行不挂车软广建达人库 + 角度库 → ② 定"火"硬阈值（自然 VV/完播/互动）→ ③ 实习生火苗监测 → ④ 火苗 **48–72h 内**投流 → ⑤ 投后盯 CPCo/流转
**坑**：同行火 ≠ 你的品火；自然火 ≠ 投流后高效。

## 实习生素材排除硬标准
- **KANS 本土商品卡**：手摇素材直接排除；近 7 天 ROI < 1.5 且消耗 > ¥100 且非 KOL 素材 → 结合内容质量判断
- **KANS 本土直播间**：近 7 天消耗 > ¥70 且 ROI < 1 → 直接排除
- 一叶子 / 跨境：阈值未定，只出观察清单
- **投流码三一致检查**：投流码链接 ↔ 素材 ↔ 投放链接；不一致 → 反馈对应 BD 更正，**不自己改**
- 直播间素材的投流码**由剪辑老师加，实习生不加**
