如何生成 Windows 版 exe（用 GitHub 云端打包，全程不需要 Windows 电脑）
================================================================

原理：把这个文件夹的代码传到你自己的 GitHub 私有仓库，
     GitHub 会自动在云端的 Windows 上帮你编译出 exe，你再下载下来。
一次配置好，以后改了代码重新上传，它会自动重新出 exe。


────────────────────────────────
第一步：用 GitHub Desktop 把文件夹变成仓库并上传
────────────────────────────────
1. 打开 GitHub Desktop（你已装）。若没登录，先登录你的 GitHub 账号。
2. 顶部菜单 File → Add Local Repository…（添加本地仓库）
3. 选这个文件夹：桌面/KANS主播排名程序
4. 它会提示"这里还不是 Git 仓库，是否创建？"→ 点
   "create a repository"（创建仓库）。
5. 在创建界面直接点右下角 "Create Repository"（默认即可，.gitignore 已备好）。
6. 右上角点 "Publish repository"（发布仓库）。
   ★★ 一定要勾选 "Keep this code private"（保持私有）★★
   —— 因为代码里有表格 ID，别公开。
   然后点 Publish。


────────────────────────────────
第二步：等 GitHub 云端自动打包（约 3-5 分钟）
────────────────────────────────
7. 打包会在你 push 后自动开始。去网页看进度：
   GitHub Desktop 顶部菜单 Repository → View on GitHub（在网页打开）。
8. 在网页仓库顶部点 "Actions" 标签页。
9. 看到一条 "Build Windows EXE" 的运行记录，前面转圈=进行中，
   变绿色 ✓ = 成功（约 3-5 分钟）。
   （若第一次没自动跑：点进 Actions → 左侧 "Build Windows EXE"
     → 右边 "Run workflow" 按钮手动触发一次。）


────────────────────────────────
第三步：下载 exe
────────────────────────────────
10. 点那条绿色 ✓ 的运行记录进去。
11. 页面最下方 "Artifacts" 区，有一个
    "KANS-Host-Ranking-windows"，点它下载（是个 zip）。
12. 解压出来就是 KANS-Host-Ranking.exe。
    （想要中文名，右键重命名成 "KANS主播排名.exe" 即可，不影响使用。）


────────────────────────────────
第四步：在 Windows 电脑上用
────────────────────────────────
13. 把这个 exe 拷到任何 Windows 电脑，双击运行，不需要装 Python。
14. 首次运行若弹 "Windows 已保护你的电脑"（SmartScreen）：
    点 "更多信息" → "仍要运行"。（因为没做付费签名，正常现象）
15. 报表会生成在 Windows 的 桌面\KANS主播排名报表\ 里；
    点程序里的"打开报表文件夹"能直接定位到。


遇到任何一步卡住，把网页截图发我，我带你过。
