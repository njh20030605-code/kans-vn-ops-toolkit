# 04 · 直播间运营基准（周报/月报）

复盘对象：越南韩束 **SKINCARE 直播间**。看的是**场内承接 + GMV-MAX 投流 + 人货场**（品广那套看种草，两者互补）。

## 关键基准
| 指标 | 目标 |
|---|---|
| 月 NMV | **160 万** |
| 月底 ROI | **5** |
| 前端 ROI | 4.5–4.6 |
| 进房率 | **6%** |
| 手卡点击率 | ≥ **26%** |
| 点击下单率 | ≥ **3.5%** |
| CVR 生死线 | **> 10%** |

**素材分级**：A（CTR > 1% 且转化 > 10%）/ B / C
**长期规划**：周 GMV $30K → $500K（9月 T2 / 12月 T1）

## 口径
- 销售 & 广告取自 GMV-MAX，USD × 6.8 = RMB
- 商品 GMV：VND ÷ 3700 ÷ 10000 = 万 RMB
- 退款率 = 取消订单额 / 总订单额（联盟后台筛非合作 skincare）
- NMV = 退后，GMV = 退前

## 周报固定 12 步
大盘洞察 → 直播间 GMV → 相关性 → GMV-ROI 对比 → 退款率 → 短视频占比 → 竞品 → 流量结构 → 品广归因 → 单链接 → 主播 PK + 综合评分 + 时段

## 主播排名
- 排名口径 GMV Host = **退前 GMV**
- **日排名只发前一天**，当天数据不统计；当月总排名也截止到昨天（不含今天）
- 10 位主播：美安 / 方灵 / 金巧 / 成发 / 智浩 / 阿东 / 天金 / 阿富 / 燕儿 / 黄草（跨 SKINCARE 与 OFFICIAL+KHTH 两个直播间加总）
- 汇率 1 元 = **3860 盾**
- ⚠️ 透视表对不上通常不是 bug：软件当月不含今天，用户透视表含今天
