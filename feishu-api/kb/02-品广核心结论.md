# 02 · 品牌广告（C-ads / 种草）核心结论

## Q2（3–6月）五条

1. **Always-On 是胜负手**。5月每日持续投 vs 3/4月间歇 → 全漏斗转化效率（卡片口径）是 3/4 月的 **2.2–3.4×**。归因新买家 68→438→**5,521**；新买家成本 5.97→3.34→**1.09**；C-ads ROAS 4.11→6.49→**14.39**（均 7 天口径）。
2. **CPCo 上升 ≠ 变差**。5月 CPCo 0.05（↑，受 5.5 大促 CPM ↑3.4× 推动），但下游转化质变。不能只看 CPCo。
3. **频次是机制铁证**。转化几乎只发生在被反复触达的人。5月频次 10+ 档转化流转率 **3.74%** ≈ 频次1档（0.01%）的 **~374 倍**，这一档贡献 **44% 买家**。持续投放 = 把人推到高频档。
4. **品广看 skill，GMV Max 只辅助**。不挂车种草选品看 6sVTR（钩子）+ 种草效率 + CPCo，**不是**带货 GMV/订单。
5. **品广对品牌搜索无可证明拉动**。日级相关弱且不一致；品广体量小，搜索由自然/达人/大促主导。5月品牌健康确有改善（搜索排名 96→99→75、行业占比 0.13%→0.22%）但无法单独归功品广。
   ⚠️ 风险词簇：`kans bị phốt`（被曝光）、`kans việt nam xin lỗi`

**规模**：新增种草 Co 56,761→100,307→130,516；6秒完播率 6.57%→8.70%→13.68%；投放天数 8→14→22 天。
**GMV Max 整月**（3/4/5月）：GMV 179,141 / 116,148 / 279,632；ROI 3.67 / 3.50 / 3.28。
**O5A（卡片·30天）**：全漏斗 Conv/Aw 0.099% / 0.154% / 0.333%；Conversion 行业排名 117→126→**83**/174。
**6月**（17天·含6.6大促，vs 5月按天数归一）：品广日均消耗 **+114%**、GMV Max 日均收入 **+57%**。

## 6月增量分析：真瓶颈在收割端

漏斗拆三段（TTMS 7天、去重 161 品牌）：

| 环节 | KANS | 行业均值 | 头部Top10 | 判断 |
|---|---|---|---|---|
| **A→C** 种草人群效率 | **2.92%**（排 25/161） | 1.78% | 3.50% | **强**，是均值 1.64×、Top10 的 83% |
| **C→V** 种草→成交 | **0.20%**（排 74/161） | 0.22% | 0.32% | **短板 = 瓶颈**，只有 Top10 的 64%（约 2/3，差 1.6 倍）|
| **A→V** 总流转 | 0.0059% | — | 0.0117% | 差头部 **2×** |
| **CPCo** ↓优 | $0.046 | $0.052 | $0.037 | 优于均值，比 Top10 贵 22% |

**结论**：种草端基本够了（A→C 已 83%、CPCo 已优于均值）；**真正要追的是 A→V 总流转，缺口几乎全在收割端 C→V**；CPCo 顺手压 22%。
KANS TTMS 官方综合排名 **86/174**（中游偏下，环比 ▼16）。

**品广种草贡献 ≈ $50.6K / 种草 ROI ≈ 1.6**（6月）。算法：品广 $31,648 → 建 Co 819,696 → ×（O5A 30天 Cons→Conv 流转 0.62%）× AOV $9.94。1.6 是**上界**（品广 Co 占全品牌新增 Consideration 92%，偏高估；真值 0.6–1.6）。
四个锚点：当天 floor **0.13** / funnel **1.6** / 7天归因 **14.4**（过度归因）/ GMVMAX 收割 **3.7**。

**当天口径品广是净成本**：品广占营销 11%→24% 时，GMVMAX 自身 ROI 不变（3.7），但总营销 ROI（全店收入 ÷[GMVMAX消耗+品广消耗]）3.24→2.81 被摊薄。隐含品广边际 ROI ≈ 0.13。

**账户抓手**：老户 KANS02 CPCo $0.032（种草 ROI ~1.9）vs 新户 MAX $0.113（ROI ~0.55 浪费）→ 砍新户或挪回老户。

## 预算决策框架：两本账

- **GMVMAX = 效果账**，收割现有需求，按 ROAS 考核（3.7，放量）。
- **品广 = 品牌/种草账**，建 Co 池 / 品牌资产 / 防守份额，是这个品类**必须交的"种草税"**（欧美 top 花 15–20% GMV）。

> **核心句：「种草是地基（必花），增量是赠品（白赚）」**
> 品广 ROI 1.6 不是"没打过 3.7"，是这笔种草钱本来就要花、还把自己赚回 160%。

**日预算**：现状品广 1.6 < GMVMAX 3.7 → **GMVMAX 主力**；品广压到 **~8% GMV**（现状 ~13% 偏高），全走老户、砍新户。
**杠杆 = 修流转率**：C→V 从均线 → 头部 Top10 0.32%（**×1.6**）→ 品广种草 ROI **1.6 → 约 2.5**，缩小与 3.7 的差距但**不再反超**。手段：GMVMAX/直播间 retarget 已种草（Consideration）人群 + 强化承接。

**脊柱判断**：每分种草预算先判断买的是**资产**（停投仍有回报）还是**费用**（停投即停效）。
三道闸门 = 单位经济正 / 资产沉淀 / 预设止损线。
案例：瑞幸 ✅ / Liquid Death ✅ vs 完美日记 ❌（复购 30.8%→2.6%，砍营销即掉收入）。
