# 本地知识库（kb/）

丢进这个目录的文件，飞书机器人**每次回答前都会自动读一遍**并塞进提示词。
机器人被告知：**这里的内容是权威事实来源，可以直接引用；这里没有的不许编造。**

## 怎么用

把文件放进来就行，不需要重启机器人（30 秒缓存，也可以在群里发 `/kb reload` 立即刷新）。

```
kb/
├── README.md              ← 本文件
├── 持仓.md
├── kans/
│   ├── 越南投放口径.md
│   └── 达人名单.json
└── 竞品/
    └── 2026Q2.txt
```

## 规则

| 项 | 值 |
|---|---|
| 支持格式 | `.md` `.txt` `.json` |
| 忽略 | `.` 开头的文件和目录 |
| 单文件上限 | 100 KB（超了不注入，`/kb list` 里标 `✗超100KB`） |
| 注入总量上限 | 60 KB |
| 子目录 | 递归扫描，层数不限 |
| 目录不存在 | 静默跳过，不报错 |

**超出 60KB 怎么办**：不是简单砍掉。会用你当轮提问里的关键词给每个文件打分（中文按二元组、英数按词），命中多的优先注入，剩下的按修改时间倒序补位；被丢掉的文件名会在提示词末尾标注 `[已截断：…]`，模型知道自己没看全。

没超上限时，按**修改时间倒序**全部注入。

## 群内指令

| 指令 | 作用 |
|---|---|
| `/kb list` | 列出所有文件 + 大小 + 本轮是否被注入 |
| `/kb reload` | 立即重新扫描（跳过 30 秒缓存） |

指令走快速通道，不会调用模型，秒回。

## 换目录

```bash
export FEISHU_KB_DIR=/path/to/your/kb
```

或在 `启动机器人.command` 里加这行。

## 写法建议

- **一个主题一个文件**，文件名写清楚——文件名也参与关键词匹配
- 结构化优先：表格、列表比大段散文好用
- 数字标注口径和时间，例如「2026-08-25 收盘」「汇率 3860」
- 会过期的内容写上日期，别让机器人拿旧数当新数

## 隐私提醒

这个目录的内容会**完整发给模型**。别把不想让模型看到的东西（密码、密钥、无关的私人材料）放进来。
