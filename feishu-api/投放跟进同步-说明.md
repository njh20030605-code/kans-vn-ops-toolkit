# 投放跟进工作台 · 双向同步

多维表格：https://你的域名.feishu.cn/base/填多维表格appToken
工作台表：tbl填表ID　源表：其余 8 张产品表

## 口径
进工作台的条件 = 源表「投流码 Ad Code」非空 **且**「投放跟进人」为空。
去重靠源表 record_id（存在工作台「行号 Row」列），**不依赖「已汇总到跟进台」勾选框**。

## 状态机
```
待填写 ──我填备注──▶ 已退回BD ──BD改投流码/删掉备注里的【投放退回】块──▶ 待填写
   └──源表有人认领（投放跟进人非空）──▶ 已写回 ──▶ 自动摘掉源表的【投放退回】标记
```
- 备注写回源表「备注 Remark」时用 `【投放退回】` 标记块**追加**，BD 自己写的内容不会被覆盖。
- 源表「同步信号」同时写一条：`投放退回 | 时间 | 备注 | 被退回的码尾号 xxxx`。
- 备注写回只在「待填写」时触发；已写回的行不再回写（防死循环）。

## 运行
- 常驻：launchd `com.jasper.followup-sync`，30 秒一轮，日志 `logs/followup-sync.log`（无变更的轮次不写日志，每小时一次心跳）。
- 重启：`launchctl kickstart -k gui/$(id -u)/com.jasper.followup-sync`
- 手动：`node followup-sync.js --once`　空跑：`node followup-sync.js --once --dry-run`
- 改频率：编辑 `~/Library/LaunchAgents/com.jasper.followup-sync.plist` 里 `--watch` 后面的秒数，再 bootout/bootstrap。
