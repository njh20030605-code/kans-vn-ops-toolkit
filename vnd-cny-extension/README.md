# TikTok / Shopee 越南后台 VND→人民币 实时汇率换算插件

> 作者：**Jasper Yang** · 仅供内部使用，勿外传 / 勿用于盈利 · Beta 测试版

把 TikTok 和 Shopee 越南后台里显示的越南盾（VND）金额，按**实时汇率**自动替换成人民币（¥）。

- **TikTok**：商家中心、Ads Manager、直播 LIVE Dashboard 等所有页面（数字在后、如 `62.142.512đ`、`897,7Trđ`、`3,9Tđ`）。含**跨境店商家中心**（seller.tiktokshopglobalselling.com，v1.5.0 起支持）。
- **Shopee**（banhang.shopee.vn）：商业分析/数据中心等页面（符号在前、如 `đ89.684.715`、明细表 `đ22.653,20K`）。

按域名自动分流：Shopee 一套逻辑、TikTok 一套逻辑，互不干扰；数字解析会自动判断逗号/点谁是小数点，两边都不会算错。

## 安装（Chrome / Edge）

1. 解压后把 `tiktok-vnd-cny` 文件夹放到电脑上一个固定位置（别删）。
2. 地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）回车。
3. 打开右上角「开发者模式 / Developer mode」。
4. 点「加载已解压的扩展程序 / Load unpacked」，选中 `tiktok-vnd-cny` 文件夹。
5. 刷新 TikTok 后台页面。

## 用法

- 点浏览器右上角插件图标：看当前汇率、更新时间，可手动「刷新汇率」，也有开关随时关闭换算（关闭后刷新页面即恢复原始 VND）。

## 支持的格式

- 完整数字：`22,693,077 VND`、`4.102.400đ`、`132.122.753đ`
- 缩写：`8.7Mđ`、`209.2Mđ`、越南文 `210Trđ`（Tr=百万）、`Tỷ`（十亿）
- 无货币符号但卡片标签是钱的：`Attributed GMV (₫) 19,652,460`、`18.48M`、`Ads Cost`、`GMV per hour`、`GPM`、`AOV`、`成本`、`收入`、`客单价`

## 不会误伤

- 观看数、曝光、点击、客户数、订单数、百分比等不换算。
- 只有百万级缩写或 ≥100 万的完整数字才当作 VND 金额（`118.24K` 这类千级视为计数）。
- 内置上限保护：位数 >13 或金额 >1 万亿 VND 一律跳过，避免出现异常放大的数字。

## 说明

汇率来源 `open.er-api.com`（免费、无需 key），每 6 小时自动刷新。这是把「显示」换算成人民币方便查看，不改变 TikTok 实际结算货币（结算仍是 VND），汇率为参考值。
